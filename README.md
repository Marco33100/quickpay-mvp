#  QuickPay MVP - Guía de Inicio Rápido (Onboarding)

¡Bienvenido al equipo de desarrollo de QuickPay! Esta guía te permitirá clonar el proyecto y tener el entorno local completo corriendo en menos de 5 minutos.

## Requisitos Previos
Antes de iniciar, asegúrate de tener instalado en tu computadora:
* [Docker Desktop](https://www.docker.com/products/docker-desktop/)
* [Git](https://git-scm.com/)

##  Levantar el Entorno Completo (Un solo comando)
1. Clona este repositorio:
   ```bash
   git clone [https://github.com/tu-usuario/quickpay-mvp.git](https://github.com/tu-usuario/quickpay-mvp.git)
   cd quickpay-mvp

2. Encender todo el sistema con:
    docker-compose up --build
